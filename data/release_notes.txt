Release 1.12.0 | July 15, 2026
Introduced Guide to Processing Personnel Actions (GPPA) Navigator, a searchable reference tool for federal HR personnel action coding
GPPA Navigator is a new web-based tool available under Policy & Guidance > Tools that helps HR Specialists identify the correct codes for personnel actions without manually searching across the GPPA PDFs.
Guidance reflected in the Navigator is current as of July 2026. This is the initial release.
Rule search and filters
Search GPPA tables by keyword across all chapters, or browse by chapter and table.
Narrow results by Nature of Action Code (NOAC) or Legal Authority Code (LAC).
Codes and remarks, and export
View the NOAC, LAC, and notes for the selected rule.
Browse and search required and additional remarks, filtered to the relevant chapter.
Review a complete summary of selections and linked references and export to a Word document.
Updated FWD Data Dictionary
Includes definitions for duty station city, department, department code and pathways group.
Duty Stations page loads US tab automatically upon page visit
Users no longer need to apply a filter before seeing results and can view the full list of Duty Stations on each tab.
Corrected bugs
Fixed minor bugs and UI design issues for an improved user experience.
